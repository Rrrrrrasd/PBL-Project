# 지역축제정보 제공 웹 애플리케이션

경상국립대학교 컴퓨터공학과(부)<br>
유연보, 임경우, 변중수

## 1. 사용기술스택
SpringBoot, Javascrip, Bootstrap, h2, RestAPI

## 2. 주요기능
- 기간별 축제 정보 제공(음식점, 숙소, 축제)
- 월별 축제 정보 제공(음식점, 숙소, 축제)
- 로그인, 회원가입 등 회원기능
- 리뷰등록기능
